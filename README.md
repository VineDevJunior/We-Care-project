## 📌 Sobre o projeto

O **Pet Care Landing Page** é uma página institucional moderna e limpa, criada para um serviço de cuidados com animais de estimação.

Este projeto foi desenvolvido como um dos meus primeiros exercícios práticos no front-end, com o objetivo de fixar os fundamentos de estruturação web, HTML semântico, estilização e posicionamento de elementos com CSS.

## 💻 Tecnologias

O projeto foi construído utilizando tecnologias web puras, sem uso de frameworks ou bibliotecas externas:

* **HTML5** - Estrutura semântica (cabeçalho, barra de navegação, seção principal, textos e botões)
* **CSS3** - Estilização de layout, tipografia moderna, paleta de cores, botões com efeitos e posicionamento de elementos

---

## ⚙️ Funcionalidades

- [x] Barra de navegação no topo com links de menu (`Início`, `Sobre`, `Produto`, `Serviços`, `Contato`)
- [x] Botão de Login estilizado no menu principal
- [x] Seção principal (*Hero section*) com mensagem focada no cuidado com pets
- [x] Botão de chamada para ação (`Explorar`) com visual destacado
- [x] Layout responsivo e alinhado combinando textos e ilustrações vetoriais

## 👷 Instalação e Como Executar

Por ser um projeto estático em HTML e CSS, você não precisa do Node.js ou de qualquer gerenciador de pacotes.

### 1. Clonar o repositório
```bash
$ git clone https://github.com/VineDevJunior/We-Care-project.git
```
### 2. Abrir o projeto
Acesse a pasta do projeto e abra o arquivo index.html em qualquer navegador:
```bash
$ cd petcare-landing-page
```
